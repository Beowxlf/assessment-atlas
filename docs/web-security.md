# Native web trust boundaries and verification — 0.4.0

## 0.4.0 additions

Optional protocol engines use the same pinned scope, verified hostname/CA TLS and bounded request/body/wire limits. HTTP/3 uses a connected UDP socket with no migration/0-RTT/Alt-Svc/fallback. Classic WS/WSS capture/edit/replay and scoped browser messages have direction, size, operation/time and both-direction interception guards. Failed authenticated handshakes retain metadata; closing a manual channel discards raw buffers and its credential copy. HTTP/DNS receivers default to loopback and require explicit interface/exposure authority, bounded short-lived unpredictable tokens, no recursive DNS, and no raw callback body retention. Actual receipts create source-reported findings with immutable probe/baseline correlation; target causality remains unknown. Callback/control ports are excluded from active transport. Additional file/stateful checks require explicitly owned isolated canaries; cleanup/reset is operator responsibility where budget/session/invalidation prevents it. [Exact contract](protocols-and-callbacks.md), [decision](adr/0005-protocols-and-owned-interactions.md).

Real TLS h2/QUIC h3, CA rejection, WS/WSS text/binary, both-direction edits, authenticated budget/scrubbing/discard, actual HTTP/DNS callbacks, API workspace/origin guards and vulnerable/fixed family tests pass locally. Isolated Edge WSS capture and outside-scope rejection pass in the browser workflow. These are fixture qualification, not an independent protocol fuzz/security audit or general scanner accuracy corpus.

## 0.3.0 additions

The table below preserves the historical 0.2.0 review. Authenticated scans additionally enforce workspace-owned transient profiles, exact-origin cookie/header isolation, secure/path/expiry cookie rules, an anonymous-vs-protected session sentinel, periodic/unauthorized/final guards and at most two explicit-sequence refreshes. Login bodies are metadata, known session values are scrubbed from later excerpts, and sessions clear on expiry/discard/restart. Active proxy listeners and IPv4-mapped control/metadata addresses are excluded from scan transport. Custom literal rules, codecs and OpenAPI inventory execute no imported code or implicit network. Downstream response edits retain the original upstream evidence and manual modification labels. [Contract and residual limits](authenticated-scans.md), [decision](adr/0004-transient-authenticated-audits.md).

Synthetic tests cover auth failure/loss/refresh, origin/workspace/cookie-path/Secure/expiry isolation, secret-free normalized DB/exports, CSRF hidden/header extraction and form/JSON escaping, controlled injection positive/fixed cases, source derivation preservation, response edits and live browser handoff over verified fixture TLS. No independent security audit or general scanner-accuracy benchmark is claimed.

Owner-authorized local product work, synthetic fixture tests and bounded owned NorthGate GET collection. This is an engineering review, not independent penetration testing or a compliance certification.

| Concrete threat | Implemented boundary | Verification and residual |
| --- | --- | --- |
| Imported URL directs outbound collection | Import normalization contains no network/subprocess path; active tools require separate authenticated operator action | Existing inert-import tests plus web-envelope no-network test; imported source labels are assertions |
| Redirect, DNS rebinding or ambiguous path leaves authority | Exact origins/path prefixes/exclusions; per-session address pins; actual connections use pinned IP with original TLS hostname; link-local/metadata/multicast/control targets blocked | Redirect/exclusion, path traversal encoding, changed resolution and self-control target cases; no universal IDNA/URL-parser corpus claimed |
| Cross-site/cross-workspace tool execution or raw buffer access | Loopback Host, HttpOnly SameSite session, Origin/nonce mutation checks; workspace checks for jobs/proxy decisions/comparisons | Actual web API negative origin/nonce/session, out-of-scope request and cross-workspace compare tests |
| HTTP framing/header injection | Controlled Host/connection/length, duplicate/newline header rejection, no chunked uploads; scoped RFC6455 upgrades, bounded text bodies | Header smuggling cases and actual HTTP/TLS proxy exchange; HTTP/1.1 subset, no full protocol fuzz audit |
| Proxy abuse or private-key exposure | Loopback only; random Basic proxy credential; scope on CONNECT and every HTTP request; ephemeral memory CA; restrictive temporary-key folder; leaf key removed after load | 407 before request, scoped actual edit/forward, HTTPS fixture trust, no residual PEM leaf keys; other software in the same OS user remains trusted |
| TLS bypass/host impersonation | No upstream verify-disable option; normal hostname/CA TLS context with optional public owned CA; test browser trusts only its generated proxy CA SPKI | Negative wrong upstream CA plus actual isolated Edge HTTPS session; no global trust/profile changes or existing lab certificate replacement |
| Runaway requests or hidden resumption | Limits, rate delay, depth/wordlist/payload bounds, cancellation, pending timeout, time-bounded browser/proxy, no restart resumption | Request limit, retained cancellation/partial results, interrupted-state migration and UI stop; an in-flight request can finish |
| Sensitive data persists or leaks through reports | Query values/sensitive headers withheld; metadata default; bounded optional redacted excerpts; credentials/CA key not in DB/logs/exports; plans withheld by default | Synthetic secret fields/header/query/body cases and authenticated browser credential tests; best-effort scrubbing can miss arbitrary secrets in paths/content |
| Existing workspace loss/downgrade exposure | Exact schema-1 SQLite backup before schema 2; existing observations/IDs preserved; old app rejects newer schema | Migration backup contents and historical reimport tests; OS backup custody/retention remains owner-controlled |
| Raw server HTML executes in Atlas | Text-node inspection, escaped reports and bounded parsing; only native trusted static template uses innerHTML | Existing hostile HTML/XML and actual UI no-page-error/non-loopback UI request checks; inspected app HTML does not execute |

Data classes: source-normalized evidence and runs persist in local SQLite; raw request/response/editor buffers are transient; CA private key is memory-only; cookie sessions belong to the isolated browser context. Public CA downloads and owner-created exports/backup copies remain outside deletion. Stored body/source digests do not substitute for protected raw originals. Node/Playwright/cryptography and h2/aioquic/wsproto are optional native-browser/TLS/protocol dependencies; source-only package includes no third-party runtime, private data or keys.

Material unqualified areas: full protocol/interoperability security, large/concurrent workload, adversarial browser isolation, universal authentication/SPA behavior, complete scanner coverage/accuracy, app encryption/multiuser security and forensic erase. See [capability/backlog matrix](native-web-coverage.md); absence of a supported check is never a clean security verdict.
