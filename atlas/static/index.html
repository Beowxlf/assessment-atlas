BRING YOUR RESULTS TOGETHER

Import results

Preview before saving. Imports never run commands, contact targets, or fetch URLs.

Supported inputs

  • Nmap XML: hosts, addresses, names, ports, OS matches, scripts and traceroute hops.
  • Nessus v2 .nessus: hosts, plugin findings and endpoint claims. Policies are discarded.
  • Nuclei: template matches as scanner assertions.
  • ProjectDiscovery httpx: observed web response metadata.
  • Linux iproute2: interfaces, address assignments, operational routes and local neighbors in a versioned bundle.
  • Common evidence JSON: reviewable manual entities, observations and relationships.

Maximum file size: 8 MiB. UTF-8 text only. No archives, PDFs, .db files, template execution, or live scanners.

Missing collection time and testing position remain unknown. Changed metadata creates a new import; an identical repeat is skipped.

Review files for sensitive data before importing. Secret detection is best effort; inspect excerpts before sharing.

A CLEAR, TRACEABLE HANDOFF

Reports & exports

Export the current map filters and linked results. Preview redactions before downloading.

Default exports withhold identifiers and free text. Included excerpts may contain sensitive data; this tool cannot guarantee removal of every secret. Original files are never embedded.

The printable report opens in a browser and can be printed to PDF. Structured results retain typed relationships, provenance, uncertainty, conflicts, identity decisions, and history.

Local storage & cleanup
Workspaces persist between sessions on this computer. Protect this folder with your operating-system account and disk encryption. Downloaded reports and your original files remain your responsibility after workspace deletion.
