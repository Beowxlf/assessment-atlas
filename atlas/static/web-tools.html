NATIVE WEB ASSESSMENT

Web workbench

Collect deliberately. Every saved request, response, endpoint, parameter and check belongs to this workspace’s evidence.

Target and collection scope

Imports stay inert. These tools make real requests only after you set the scope. Crawling uses GET; forms are discovered without automatic submission.

Additional origins, exclusions and trusted CA

Crawl links and discover paths

Outside-scope redirects are recorded and blocked. A returned path/status does not establish directory traversal, physical topology or a vulnerability.

Edit and resend a request

The editor and raw bounded response are transient. Headers/credentials are not saved for automatic replay. Enter authenticated values only in this local editor or the isolated browser.

Bounded tests of one selected parameter
Uses the request URL, method, headers and body from the editor. Makes one baseline request, then one request per supplied payload. It does not guess credentials or start a wider scan.
Reflection and status changes are indicators for review; they do not prove script execution or exploitation. Methods such as POST/DELETE can change application state.

  
Local HTTP and HTTPS interception
Start an authenticated loopback proxy for this exact scope. Forward requests unchanged or edit them live; drop unwanted requests. Pending requests fail closed after 30 seconds.
An ephemeral Atlas CA is generated in memory. Existing certificates, global trust, browser profiles and Burp settings are untouched. HTTPS requires the optional TLS library. Use the Atlas browser below, or deliberately configure a separate test browser with the displayed local proxy credentials and public CA.

  
Authenticated and JavaScript browsing
Open a fresh Atlas-owned Edge window through the scoped proxy. Sign in and exercise JavaScript flows yourself; requests, responses and parameters feed this workspace. Explicitly add any owned login/API origins before starting.
Requires Node.js, Playwright and Microsoft Edge. Cookies remain in the temporary browser context and are discarded when it closes. Service workers and WebSockets are blocked; cross-origin apps require explicit additional scope. This is interactive session coverage, not universal authentication automation.

  
Explicit original scanner checks
Fetch the scoped start URL once and check captured headers/cookies and recognized error-text signatures. Results retain source evidence and stay marked scanner-reported.
Checks: CSP, HSTS, frame policy, nosniff, cookie Secure/HttpOnly, wildcard CORS declarations and verbose error signatures. Selected-parameter tests separately identify reflection/status changes. Full Burp Scanner coverage and accuracy have not been established; advanced injection, authorization, out-of-band, WebSocket and statistical token analysis remain unfinished.
